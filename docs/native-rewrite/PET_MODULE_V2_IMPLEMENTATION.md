## 当前明确限制

- 猫砂自动事项禁止单独删除，避免库存与状态失去一致性；统一撤销/编辑历史操作界面尚未提供。
- 图片目前以内嵌 Base64 保存，尚未实施独立文件压缩与清理策略。
- 正式产品只适配 iPhone 竖屏；iPad 横屏、iPad 分屏及 iPad 正式布局不属于本模块范围。
- iPhone 竖屏、动态字体、深色模式和前后台恢复尚未真机验收。
- Windows 环境没有 Swift/Xcode 编译器；本轮完成静态检查与 Playgrounds 同步。iPad Playgrounds 只用于预览交互，不能代替 iPhone 正式构建与真机验收。
- 当前已生成 `0.1.11 (12)` 未签名 IPA；未迁移 Web 数据，未修改 Web `main`。

## 本轮预览验收顺序

1. 设置 → 宠物管理：创建两只宠物。
2. 设置 → 宠物事项设置：创建“日常护理”“健康”“猫砂护理”等分类。
3. 宠物 → 新增宠物物品：至少创建两个 kg 猫砂产品和一个宠物食品。
4. 初始化猫砂余量，确认家庭库存不变。
5. 补猫砂，确认家庭库存、猫砂进度和时间轴同时刷新。
6. 换猫砂，确认旧基准被替换且历史仍保留。
7. 添加普通事项，检查日期分组、筛选、详情、编辑、删除和图片。
8. 返回首页，检查宠物状态读取真实预测和食品库存。
