# Home OS 原生重写功能基线

基线来源：Web v8.25.1。原生实现不得通过 `WKWebView` 嵌入 Web 页面。

## 全局

- 五个固定入口：首页、食品、菜谱、宠物、设置。
- 页面层级使用原生导航，详情页和编辑页必须有可用返回按钮。
- 点击、库存调整、保存、删除等操作使用分级震动反馈。
- 数据默认只保存在当前设备，支持 JSON 备份导入导出。
- 原生版本与 Web 版本分别记录版本号和功能基线。

## 首页

- 宠物状态位于首页最上方。
- 临期提醒展示过期和即将到期食品，点击进入食品详情。
- 食品快捷管理采用食品库存同款列表和展开操作逻辑。
- 菜谱计划仅在有计划时展示，点击进入准备检查。
- 最近动态展示食品、菜谱计划和宠物操作记录。

## 食品

- 搜索、分类、标签、临期筛选和排序。
- 新增食品，支持生产日期、保质期自动计算或手动到期日期。
- 食品图片、名称、数量、单位、品牌、规格、位置、分类和标签。
- 食品详情、库存增减、购买记录、价格历史和首页快捷开关。
- 快捷减少档位可配置，库存变化写入最近动态。

## 菜谱

- 我的菜谱、收藏菜谱、食材库和三餐计划。
- 菜名、主料、配料、步骤、步骤图片、收藏分组和外链。
- 按食材反查相关菜谱。
- 计划包含日期、餐次、菜谱和备注。
- 临时准备检查状态：已有、需要购买、已购买、已准备、忽略。
- 完成后删除当次检查，不生成长期采购清单。

## 宠物

- 猫砂、猫粮/零食、猫咪偏好。
- 猫砂、猫粮、主食罐头、冻干、除臭包和其他用品。
- 品牌、型号、规格、数量、单位、预计使用天数和每周用量。
- 补充时间、购买渠道、购买价格、购买与补充历史。
- 两只猫分别记录喜欢、一般、不喜欢和备注。

## 设置

- 临期提醒总开关和不同食品阈值。
- 存放位置、食品分类、食品标签和菜谱收藏分组管理。
- 首页快捷食品顺序、快捷调整数量和首页计划显示数量。
- JSON 备份导入导出、删除测试数据和清空应用数据。
- 原生版版本信息、构建号和对应 Web 功能基线。

## 阶段验收

每个模块必须同时满足：可运行、可保存、重启不丢失、备份可恢复、无 WebView、生成未签名 IPA。
