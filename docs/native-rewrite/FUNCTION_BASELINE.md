# Home OS 原生重写功能基线

基线来源：Web v8.25.1。原生实现不得通过 `WKWebView` 嵌入 Web 页面。

## 全局

- 五个固定入口：首页、食品、菜谱、宠物、设置。
- 页面层级使用原生导航，详情页和编辑页必须有可用返回按钮。
- 点击、库存调整、保存、删除等操作使用分级震动反馈。
- 数据默认只保存在当前设备，支持 JSON 备份导入导出。
- 原生版本与 Web 版本分别记录版本号和功能基线。

## 首页

- 宠物状态位于首页最上方。
- 宠物状态卡底部固定展示主食罐、零食罐和猫砂三个真实库存统计。
- 临期提醒展示过期和即将到期食品，点击进入食品详情。
- 食品快捷管理采用食品库存同款列表和展开操作逻辑。
- 菜谱计划仅在有计划时展示，点击进入准备检查。
- 最近动态展示食品、菜谱计划和宠物操作记录。

## 食品

- 搜索、分类、标签、临期筛选和排序；搜索入口默认隐藏，下拉页面后出现。
- 新增食品，支持生产日期、保质期自动计算或手动到期日期。
- 食品图片、名称、数量、单位、品牌、规格、位置、分类和标签。
- 食品详情、库存增减、购买记录、价格历史和首页快捷开关。
- 快捷减少档位可配置，库存变化写入最近动态。

## 菜谱

- 我的菜谱、收藏菜谱、食材库和三餐计划。
- 搜索入口默认隐藏，下拉页面后出现。
- 菜名、主料、配料、步骤、步骤图片、收藏分组和外链。
- 按食材反查相关菜谱。
- 计划包含日期、餐次、菜谱和备注。
- 临时准备检查状态：已有、需要购买、已购买、已准备、忽略。
- 完成后删除当次检查，不生成长期采购清单。

## 宠物

- 宠物页直接保留高频宠物物品与快捷出入库；物品评价从物品选择器右侧入口进入独立页面，避免首页重复纵向展开同一批物品。
- 宠物物品按“宠物食品/宠物用品”一级分类和可扩展二级分类管理具体产品。
- 产品列表支持分类筛选、回购与猫咪偏好摘要，并可直接快速出库；不设置或展示预警库存。
- 当前库存由入库、出库和调整流水计算；入库价格自动形成单位价格历史。
- 新建物品的分类以单行摘要进入原生底部弹窗；只选择一级和二级分类，不设置“用途”。
- 品牌使用可搜索标签库，支持新增、改名、适用范围、停用和合并；新建物品可选填本次购入总额并自动折算单价。
- 宠物物品列表点击左侧图片与名称进入详情；点击右侧数量及空白区域展开快捷管理，不显示方向箭头。
- 宠物物品记录包装形式、单件规格和库存单位；列表支持品牌筛选，评价列表支持品牌筛选与评分排序。
- 列表以固定两行展示：品牌｜规格 × 包装库存；名称＋口味｜平均评分。包装预设当前仅有袋和罐，允许不设置。
- 宠物页顶部只按产品档案统计全部、食品和用品“款数”，不把不同规格或单位的库存相加。
- 所有产品保存独立的多维物品评价；只有食品额外保存分宠物猫咪评价。
- 物品评价按品类使用四个整数评分维度；系统计算单次综合分、历史平均综合分和各维度平均分，平均结果显示一位小数。
- 独立“物品评价”页面复用相同的两级分类和品牌筛选；历史评价按记录 ID 原位编辑，保存后重新计算综合平均分，不新增重复记录。
- 每条入库记录同时展示总价和两位小数单价，价格历史位于物品详情页最底部。
- 库存修正显示目标库存与变化量，使用显式数字校验并在原弹窗反馈失败原因。
- 猫砂家庭库存与猫砂盆当前预计余量是两个独立对象。
- 猫砂初始化不扣库存；补砂和换砂同时更新库存、猫砂盆状态和自动事项。
- 基于补砂/换砂历史估算每日消耗、预计余量、可用天数和 40% 阈值日期。
- 宠物事项不区分具体宠物，使用“事项类型必选＋具体事项选填”；首页以连续竖线和节点展示两行时间轴，不再增加日期分组标题或重复名称。
- 历史事项中的宠物标识与名称快照只为备份兼容保留，新建和编辑事项不再写入。
- 所有用户可见日期使用 `yyyy年M月d日`，不显示英文月份；备份字段继续使用 `yyyy-MM-dd`。
- 停用产品保留全部库存、价格和评价历史，但从日常列表隐藏。

## 设置

- 临期提醒总开关和不同食品阈值。
- 存放位置、食品分类、食品标签和菜谱收藏分组管理。
- 全局分类管理与品牌库管理；停用品牌保留历史关联名称。
- 首页快捷食品顺序、快捷调整数量和首页计划显示数量。
- JSON 备份导入导出、删除测试数据和清空应用数据。
- 原生版版本信息、构建号和对应 Web 功能基线。

## 阶段验收

每个模块必须同时满足：可运行、可保存、重启不丢失、备份可恢复、无 WebView、生成未签名 IPA。
