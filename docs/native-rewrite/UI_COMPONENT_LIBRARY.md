# Home OS 统一 UI 组件库

> 本文控制跨页面视觉与交互。业务页面不得复制一份组件后自行改变字号、圆角、按钮顺序或反馈方式。

## 1. 组件状态

| 状态 | 使用规则 |
| --- | --- |
| 已确认 | 正式业务页面必须直接复用 |
| 候选 | 只允许在设置页“UI 组件库”或 Playgrounds 中预览 |
| 调整中 | 已发现问题，不允许新增业务引用 |
| 已废止 | 旧页面逐步迁移，禁止新页面使用 |

## 2. 新组件准入流程

1. 先检查现有组件是否能满足需求。
2. 无法满足时，登记编号、使用场景、状态、动画、触感、键盘、iPhone 竖屏安全区和无障碍要求。
3. 在设置页“UI 组件库”中制作可操作预览，不直接放入业务页。
4. 用户明确确认后，把状态改为“已确认”。
5. 业务页面只能调用公共组件，不得复制源码后改变样式。
6. 修改已确认组件会影响多个页面，必须重新预览并说明影响范围。

### 3.2 字体

| 令牌 | 当前值 | 状态 |
| --- | --- | --- |
| `pageTitle` | 24pt / Semibold | 预览候选 |
| `sectionTitle` | 19pt / Semibold | 预览候选 |
| `cardTitle` | 15pt / Semibold | 候选 |
| `body` | 15pt / Regular | 候选 |
| `supporting` | 12pt / Regular | 候选 |
| `metric` | 28pt / Bold / Rounded | 候选 |

字体使用 iOS 系统字体，由系统为中文选择合适字形。动态字体、较大辅助字号和窄屏 iPhone 仍需真机检查。

- 中文通常由 iOS 系统选择苹方（PingFang SC）。
- 英文和数字通常使用 SF Pro。
- 当前不再为页面标题指定 Rounded 设计，避免中文与数字的视觉风格割裂。
- 表单输入内容显式使用 `body`，即 15pt / Regular，不再跟随偏大的默认输入字号。

| 编号 | 交互 | 必须确认的内容 | 状态 |

| INT-01 | 页面进入与返回 | 返回目标、未保存内容、系统手势 | 候选 |
| INT-02 | 新增/编辑 | 页面或弹窗、保存位置、关闭方式、键盘 | 候选 |
| INT-03 | 单选/多选 | 展开方式、确认方式、搜索和清空 | 候选 |
| INT-04 | 日期与保质期 | 自动计算、手动选择、修改记录时间 | 候选 |
| INT-05 | 删除确认 | 按钮顺序、危险色、关联数据说明 | 候选 |
| INT-06 | Toast 和页面状态 | 持续时间、是否阻断、重试 | 候选 |
| INT-07 | 快捷数量管理 | 展开、加减、连续点击和震动 | 候选 |
| INT-08 | 搜索、筛选与排序 | 条件组合、清除和结果计数 | 候选 |
| INT-09 | 图片与文件 | 相册、相机、文件、压缩和失败恢复 | 候选 |
| INT-10 | 通知权限与提醒 | 请求时机、拒绝后处理和跳转设置 | 候选 |

## 7. UI 组件库入口

原生预览中进入：`设置 → 开发与设计 → UI 组件库`。

当前可以操作检查：字体、颜色、统计卡片、按钮、标签、输入框、属性行以及空/加载/错误/成功状态。组件库使用内存状态，不读写正式业务数据。
