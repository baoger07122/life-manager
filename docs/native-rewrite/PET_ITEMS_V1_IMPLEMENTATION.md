# Home OS 宠物物品 V1 实施基线

需求来源：`Home_OS_宠物物品功能优化_Codex执行版_V1.0.md`，读取日期 `2026-08-28`。

## 当前产品前提

- 当前没有需要迁移的正式宠物物品数据，以最新原生开发结构重新建立。
- 旧字段只保留宽容读取能力，不再作为新页面的写入来源。
- 正式使用环境仅为 iPhone 竖屏；iPad Playgrounds 只承载预览。

## 已进入原生预览

- 宠物食品、宠物用品两级分类和具体产品档案。
- 手机紧凑列表、两级联动筛选和行内快捷管理；只记录实际库存，不设置或展示预警库存。
- 点击产品图片进入详情；点击右侧内容区展开紧凑的入库/出库控件，同一时间只展开一项。
- 快捷管理只承担数量操作，不再显示“查看详情”，也不再常驻快捷出库按钮。
- 一级、二级分类与物品列表放在同一张圆角卡片内；选中态统一使用蓝色短下划线。
- 当前库存由统一流水求和，支持入库、出库和库存调整。
- 新建物品可选填本次购入总额，并按初始库存自动折算单位价格；后续入库继续按每批实际金额形成价格历史。
- 新建页分类压缩为单行摘要，点击后使用原生底部弹窗联动选择一级、二级分类；不再设置食品“用途”。
- 品牌使用可搜索、可筛选的标签库；设置页支持新增、改名、适用范围、停用和重复品牌合并。
- 宠物物品新增包装形式与单件规格，分别记录“袋/罐”包装和“5.4kg/185g”等净含量；未设置包装时库存单位继续独立记录。
- 包装形式当前只提供“袋”“罐”两个预设，并允许保持未设置；选中后同步作为库存单位。口味恢复使用独立 `variant` 字段，不再被规格覆盖，不同口味作为不同产品保存。
- 宠物物品列表保持原两行高度：第一行品牌与“规格 × 当前包装库存”，第二行名称加口味与平均评分；不增加第三行。
- 宠物页标题下增加全部物品、宠物食品、宠物用品三项款数统计，避免混合袋、罐、kg 等库存单位求和。
- 宠物物品列表提供品牌筛选；评价列表同时提供品牌筛选和评分高低排序。
- 所有产品支持多次评分与文字评价。
- 评价升级为多维整数评分：宠物食品使用适口性、品质、性价比、回购意愿；宠物用品使用使用效果、便利性、耐用性、性价比。单次综合分和历史平均分由系统计算并显示一位小数。
- 宠物页在物品列表后增加独立“物品评价”模块，复用一级、二级分类筛选；物品列表右侧在库存下显示历史平均分。
- 入库界面、库存流水和价格历史同时展示总价与单位价格，金额固定两位小数；价格历史固定在详情页最后。
- 入库总价默认留空，以 `¥0.00` 作为占位提示；详情页采用紧凑商品卡、右侧库存操作、评分总览和表格式价格历史。
- 用户可见日期统一使用 `yyyy年M月d日` 中文格式，JSON 仍保存为 `yyyy-MM-dd`。
- 宠物事项不再区分或筛选具体宠物，按日期时间轴展开；旧事项中的宠物快照仅作为兼容数据保留。
- 快捷入/出库使用 34pt 可见加减按钮与 44pt 点击区，数量支持直接输入；快捷入库可选填总价并自动计算单价。
- 库存修正使用文本解析并展示修正前后差值；无变化、非法输入和保存失败均在当前弹窗反馈。
- 新增宠物物品、宠物事项和添加评价入口统一触发轻触反馈；触感发生器复用，避免每次点击重新创建。
- 评分编辑器每个维度标题与 1～5 分选择器位于同一行；备注框默认 52pt、左对齐且单行时垂直居中，多行时向下扩展。
- 仅宠物食品支持按宠物分别记录多次猫咪评价。
- 猫咪偏好页面按宠物和产品汇总最新评价。
- 猫砂补砂、换砂会同时写入关联出库流水，不要求重复登记。
- 停用产品隐藏于日常列表，但保留其流水、价格和评价。
- 设置页提供统一“分类管理”入口；宠物、食品、菜谱复用管理组件但保持独立分类树。
- 设置页提供统一“品牌管理”入口；停用品牌不删除历史物品上的品牌名称。
- “宠物食品/宠物用品”保留稳定系统能力标识，可改名、排序，不可物理删除。

## 仍需正式构建验证

- 当前 Windows 环境不能编译 Swift；需要在 Swift Playgrounds 打开确认语法和页面行为。
- 猫砂操作的编辑或删除回算界面尚未完成，目前继续禁止单独删除关联事项。
- 历史流水和评价的“查看全部”、编辑及删除入口尚未完成；当前详情显示最近记录。
- 图片仍以内嵌 Base64 保存，尚未实施压缩与文件清理。
- 已生成 `0.1.13 (15)` 未签名 IPA；未修改 Web。

## Playground 测试夹具

- `PlaygroundPackage.swift` 单独定义 `PLAYGROUND_PREVIEW`，正式 Xcode/IPA 构建不包含该标记。
- 预览沙盒为空时自动载入食品、菜谱、宠物物品、库存流水、猫砂状态和宠物事项测试数据。
- 设置页“Playground 预览”可以手动重新载入测试数据；覆盖范围仅限预览沙盒。
